# homebrew-routeconverter

Homebrew tap for [RouteConverter](https://www.routeconverter.com/).

```bash
brew install --cask cpesch/routeconverter/routeconverter
```

Supports Intel and Apple Silicon Macs. The app is signed but not
notarized by Apple; see the cask's caveats for the Gatekeeper workaround.
